# Capture checklist — fill this in BEFORE recording

Copy this folder to `ai-agency/demos/<slug>/` for every new episode.

- [ ] **Before state** captured on screen: the manual process as it actually
      looks (the messy inbox, the blank spreadsheet, the Slack backlog) — this
      is the pain shot, don't skip it.
- [ ] **The build**, screen-recorded: the automation/agent/workflow actually
      running, tool chrome visible (n8n canvas, terminal, agent UI — whatever
      it really is), cursor visible, no dead air.
- [ ] **The payoff shot**: the result landing — the CRM row appearing, the
      email going out, the dashboard updating. Don't cut before this lands on
      screen; it's the single most important frame in the video.
- [ ] Record at the tool's native resolution, 60fps if available.
- [ ] Note the real numbers below — these go straight into narration.json.
