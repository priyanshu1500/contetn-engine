LexIntent Intelligence  —  Production System

Format Codex

Filed 31 Aug 2026 Contains 51 repeatable reel formats Built from Dossier 01 + 4 reel teardowns on file + viral-short-form-ideas Rule every format ships in ≤ 20 min once the OpenChatCut kit is built

Fifty structural moves, not fifty topics. Each one is a fill-in template: pick a resume line, a firm, a stat, a fear — the structure and the motion stay fixed.

Every format is tied to a fear from Dossier 01, a psychological trigger, a LexIntent column, and the exact OpenChatCut kit scenes that build it. Nothing here is rated High complexity — if a format needs a new animation, it belongs in Phase 4, not the calendar.

Fear # = ranked cluster from Dossier 01  ·  Trigger = the lever (gap / injustice / insider / loss-aversion / pattern-interrupt / proof / specificity)  ·  Build = kit scenes (Masthead · Red-pen · Score-card · Before/After · Flow · Number · Reorder · Calendar · Sheet)  ·  Cx = edit complexity  ·  Min = produce time once templates exist

How to use this codex

  1. The calendar (Phase 8) draws from here. Five reels a day = five codes pulled across families, weighted to the day’s job (curiosity days lean Case File + Number; trust days lean Recruiter POV + Signal Decode; launch push leans Dispatch).
  2. Scripts (Phase 6) instantiate a code. Each script names its format code, fills the fixed structure with one real artifact/stat/fear, and gets scored on the quality rubric.
  3. Never two of the same code back-to-back. Rotate families so the feed doesn’t feel like a template — it should feel like a publication with recurring columns.
  4. Every code’s CTA is comment-to-DM or next-edition. The resource in the DM is a teardown, checklist, or the next Dispatch. The product enters only when someone replies.

All 50 build from the OpenChatCut kit scenes already designed (Masthead · Red-pen · Score-card · Before/After · Flow · Number · Reorder · Calendar · Sheet · Stamp · handwritten note · page-flip). The two new kit pieces these formats need — a scan-line overlay and a redaction-bar reveal — are the only Phase-4 additions, and both are one motion each. Render of the kit is still blocked on machine RAM (see Dossier 01, Phase 4).
