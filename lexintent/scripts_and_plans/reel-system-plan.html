01 The script formula — decoded from @adityamultiservices_pune

AdityaMultiServices — Pune labour-law consultancy, verified, 61,465 followers on 65 posts. Recent reels: 99k / 87k / 63k / 19k likes; comment counts 1,295 · 2,521 · 2,004 · 1,274. A tiny catalogue doing influencer numbers. Here is exactly how they write, pulled from their live captions:

  1. Hook (0–3s) — second person + specific + high stakes. A named workplace threat, stated as a question or a STOP / Wait / Don't command. A number if one fits.
  2. Language — Hinglish, protective, urgent. Short sentences. "Agar … toh …". Constant you / your / tumhari.
  3. Turn (3–8s) — the reframe. "They are legally wrong." / "You are legally obligated to…" / "Nobody can force you." The moment the viewer realises they have power.
  4. Payload (8–25s) — the exact right + the exact action. Cite the act or rule, then tell them the one move to make. Numbered if there are several.
  5. CTA — comment-driven. "Comment [word]" / a phone number / "check bio". Their comments run 1,000–2,500 per post because the value is gated behind the reply.
  6. Emotion — injustice → armour. "They are quietly taking advantage of you." → "Here is your shield."

The same formula, re-pointed at law students (LexIntent)

Swap "employee vs company" for "student vs the placement system / the recruiter's 7 seconds". Same six beats.

Starter set of 10. The full Hook Bank = 50, tagged by fear (from the research) and by format, is step 1 of the roadmap.

Script template (5 parts, ~40–50s)

  1. HOOK — one of the above, on screen as kinetic Anton text + spoken. Nothing else moves.
  2. TURN — "It's not [what they think]. It's [the real reason]." One sentence.
  3. PAYLOAD — the signal rewrite / the right / the rule, shown on the CV card + signal meter. 2–3 beats, numbered.
  4. PROOF — the before→after line, meter jump, or a one-line recruiter quote.
  5. CTA — "Comment FILE and I'll DM you the full breakdown + the annotated rewrite."

Delivery notes (this is the "same-to-same" bit)

  • One idea per line. If a sentence has two clauses, it's two lines and two cuts.
  • Read 0.9× speed on the hook, snap to 1.05× on the payload, drop to 0.85× on the verdict.
  • Hard stop — a real 0.4s silence — before the CTA.
  • Every number and every "you" lands on a music transient (the beat-map).
  • Caption = the hook + the payload rewritten as text, ending in the comment prompt. This is where Hinglish reach lives even if the VO stays English.

04 The production loop

Once the three kits exist, a reel is an assembly job, not a build. Target: 1 reel/day, 5/week, every one ending in comment-to-DM.

  1. Pick a hook from the Hook Bank (tagged by fear + format).
  2. Fill the 5-part script template. Write the caption (hook + payload + comment prompt; Hinglish if the topic suits).
  3. Voice — Sarvam / your recording → the Audacity/ffmpeg post chain → beat-map to a bed.
  4. Assemble — Illustration Kit scene templates + Motion Kit type/meter/stamps, text + character swapped.
  5. Render (HyperFrames low-mem) → mux audio → −14 LUFS.
  6. Post with the comment CTA. Pin the payoff comment.
  7. Read the 48-hour data (retention, comments, DMs) → the winning hook shape gets 3 re-angles next week.
