Plan for review

One acquisition sprint (~half a day), then a monthly 30-minute top-up. Everything lands under D:\agency content\assets\ in fixed folders so OpenChatCut / HyperFrames / Remotion always resolve.

Acquisition sprint — do once

  • Fonts → assets/fonts/. Self-host via Fontsource (Newsreader, Source Serif 4, Inter) so renders don’t hit the network. Download Fontshare Zodiak / Gambetta / Sentient as the Canela-class display alternatives + one slab for a masthead.
  • Textures → assets/textures/. From Rawpixel PD: 10–15 paper / ledger / halftone / foxed-page scans. From Lost & Taken + Texturelabs: paper, ink-bleed, dust, grain. From Transparent Textures: 2–3 tileable fibre patterns for the HTML/CSS scenes.
  • SFX → assets/sfx/. Grab the current-year Sonniss GDC bundle once (extract only foley / paper / impact / cloth). Top up gaps from Mixkit + Pixabay. Put your Freesound API key in OpenChatCut\.env.local (FREESOUND_API_KEY=) to search CC0 in-app. video-shotcraft’s 16-category pack is already local — use it first.
  • Music beds → assets/music/. 4–6 minimal / ambient / underscore tracks from Pixabay Music + YouTube Audio Library (filter “no attribution”). One Musopen public-domain classical piece for archival / Case File cuts. Keep every bed for use at ≤ −20 dB under VO.
  • B-roll → assets/broll/. 10–20 Prelinger (Internet Archive) clips: offices, courtrooms, typewriters, paperwork, filing, city streets — the spine of the Archive-Collage / Case File formats. Plus ~10 modern clips from Pexels / Coverr (hands, libraries, desks, keyboards).
  • Archival stills → assets/archival/. Ornaments, rules, engraved initials, old-document scans from Rawpixel PD, Smithsonian Open Access, British Library / Internet Archive Book Images on Flickr — for the masthead furniture and the Redacted / Exhibit-A frames.
  • Icons → assets/icons/. Pin Lucide + Tabler locally; use the installed better-icons CLI for anything ad-hoc (200+ Iconify sets). Recolour to burgundy at use time.
  • Motion toolkit. Confirm GSAP premium plugins (SplitText / MorphSVG / DrawSVG) are enabled for HyperFrames — GSAP is now fully free. Add @remotion/transitions + @remotion/paths + @remotion/noise to the OpenChatCut scene toolkit.

Licence hygiene

  • Keep assets/LICENSES.csv — one row per file: filename, source, URL, licence, attribution-needed (y/n), date.
  • Nothing tagged ⚠ non-commercial (BBC RemArc, any CC-BY-NC) goes near a LexIntent post. It’s listed only so it isn’t used by mistake.
  • Prefer CC0 / Public Domain so there’s nothing to credit. Attribution-required items → a caption line or a 1-second end-frame; log them in the CSV.
  • Fonts: only OFL / Fontshare FFL / self-hosted OSS. Never a “free for personal use” face on a commercial post.

Monthly, 30 min: check Sonniss for the new annual bundle, Fontshare for new releases, and re-verify any Attribution / “check per item” source still permits commercial use. Add new finds to this file’s list.
